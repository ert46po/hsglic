
# 🖥️ Game for Linux and Android (CLI)

مرحباً بك في مستودعي! أنا طفل عمره 11 سنة، وقد برمجت هذه اللعبة بنفسي لتشتغل عن طريق سطر الأوامر (CLI) لتناسب أنظمة لينكس وأندرويد.

## 💡 لماذا اخترت CLI؟
لا تسألني ليش ما خليتها GUI! اخترت الـ CLI لأنها أبسط وأكثر تركيزاً، وكمبرمجين نحن نحتاج دائماً لمثل هذه الريبوزيتوريز التي تحتوي على ألعاب ومشاريع نصية خفيفة وسريعة.

قريباً جداً قد أقوم بتطوير نسخة بواجهة رسومية (GUI)، لكن ستبقى واجهة سطر الأوامر هي الأساس!

---

## 📥 طريقة التحميل والتشغيل (بدون تعقيد!)

عندما تقوم بتحميل المشروع، لديك احتمالين لملفات اللعبة:

### 1. إذا كانت النسخة بصيغة ملف مضغوط (`.zip`):
احتمال كبير أن تجدها بصيغة مضغوطة، وفي هذه الحالة ستحتاج لفك الضغط عنها أولاً عبر التيرمينال (Linux) أو تطبيق Termux (Android) بالأمر التالي:
```bash
unzip HackerGame.zip
بعد فك الضغط، قم بالدخول إلى مجلد اللعبة مباشرة

cd HackerGame
2. إذا كانت النسخة مجلداً عادياً:
فقط قم بالدخول إلى المجلد مباشرة عبر سطر الأوامر
cd اسم_المجلد
🚀 أمر التشغيل
بعد دخولك إلى مجلد اللعبة، قم بتشغيل اللعبة بالأمر المناسب حسب ملفاتك

python3 hacker_control.py
### 📱 طريقة تشغيل لعبة الـ GUI على أجهزة الأندرويد والتابلت:

1. نزل تطبيق **Pydroid 3** من متجر التطبيقات (Google Play).
2. افتح التطبيق وافتح ملف اللعبة (`hsglic_gui.py`) بداخله.
3. اضغط على زر التشغيل (**Run**) في الأسفل لتفتح واجهة اللعبة الرسومية وتبدأ اللعب!
