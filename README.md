# 🖥️ Game for Linux and Android (CLI)

مرحباً بك في مستودعي! أنا طفل عمره 11 سنة، وقد برمجت هذه اللعبة بنفسي لتشتغل عن طريق سطر الأوامر (CLI) لتناسب أنظمة لينكس وأندرويد.

## 💡 لماذا اخترت CLI؟
لا تسألني ليش ما خليتها GUI! اخترت الـ CLI لأنها أبسط وأكثر تركيزاً، وكمبرمجين نحن نحتاج دائماً لمثل هذه الريبوزيتوريز التي تحتوي على ألعاب ومشاريع نصية خفيفة وسريعة.

قريباً جداً قد أقوم بتطوير نسخة بواجهة رسومية (GUI)، لكن ستبقى واجهة سطر الأوامر هي الأساس!
